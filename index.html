Sumber, Nota & Penerbitan

Maklumat penting bagi penggunaan dashboard ini.

Sumber Data

Indikator diambil daripada dokumen Mesyuarat Verifikasi Data MURNInets 2.0 Tahun 2026. Kod indikator, dimensi dan halaman PDF disusun semula untuk paparan dashboard.

Nota Peta

Peta ini dibina secara embedded dalam fail dashboard supaya sempadan PBT dan label nama PBT sentiasa dipaparkan tanpa bergantung kepada servis peta luaran yang kadang-kadang gagal dimuatkan.

Nota Penting

Dokumen sumber tidak menyediakan satu skor komposit akhir keseluruhan bagi setiap PBT. Oleh itu, dashboard memaparkan analisis berdasarkan indikator terpilih dan bukannya klasifikasi keseluruhan yang direka-reka.

Cara Publish ke GitHub Pages

  1. Upload semua fail ke repository GitHub anda.
  2. Pergi ke Settings → Pages.
  3. Pilih Deploy from a branch.
  4. Pilih branch main dan folder /(root).
  5. Simpan dan tunggu 1–3 minit.
